================================================================================
                        3. 해결한 문제들
================================================================================

[문제 1] npm 명령어 인식 불가
  증상: 'npm' 용어가 cmdlet으로 인식되지 않음
  원인: Node.js가 환경 변수 PATH에 등록되지 않음
  해결: $env:Path += ";C:\Program Files\nodejs" 명령어로 임시 해결
  
[문제 2] PostgreSQL 비밀번호 인증 실패
  증상: error: 사용자 "postgres"의 password 인증에 실패
  원인: db.js 파일의 비밀번호가 'your_password'로 설정됨
  해결: 실제 PostgreSQL 비밀번호 'sj1234'로 변경

[문제 3] logindb 데이터베이스 없음
  증상: error: "logindb" 데이터베이스 없음 (code: '3D000')
  원인: PostgreSQL에 logindb 데이터베이스가 생성되지 않음
  해결: psql 명령어로 데이터베이스 생성
        $env:PGPASSWORD="sj1234"; 
        & "C:\Program Files\PostgreSQL\18\bin\psql.exe" 
        -U postgres -c "CREATE DATABASE logindb;"

[문제 4] 포트 3000 이미 사용 중
  증상: Error: listen EADDRINUSE: address already in use :::3000
  원인: 이전에 실행한 서버가 아직 실행 중
  해결: 기존 서버 프로세스 종료 후 재시작

  - 응답: { success: boolean, message: string }

POST /api/logout
  - 로그아웃
  - 응답: { success: boolean, message: string }

GET /api/current-user
  - 현재 로그인한 사용자 정보

GET /api/users ⭐ NEW
  - 전체 회원 목록 조회
  - 인증 필요: 로그인한 사용자만 접근 가능

                        13. 문제 해결 팁
================================================================================

[서버가 시작되지 않을 때]
  1. PostgreSQL 서비스가 실행 중인지 확인
  2. db.js의 비밀번호가 올바른지 확인
  3. logindb 데이터베이스가 존재하는지 확인
  4. 포트 3000이 사용 중인지 확인

[브라우저 접속이 안 될 때]
  1. 서버가 실행 중인지 확인
  2. 터미널에 "Server is running" 메시지가 있는지 확인
  3. 방화벽 설정 확인
  4. 브라우저 캐시 삭제 후 재시도

[npm 명령어가 인식되지 않을 때]
  1. Node.js가 설치되어 있는지 확인
  2. PowerShell을 재시작
  3. 환경 변수 PATH에 Node.js 경로 추가
  4. 임시 해결: $env:Path += ";C:\Program Files\nodejs"

[회원 목록이 표시되지 않을 때]
  1. 로그인 상태 확인
  2. 브라우저 콘솔에서 에러 메시지 확인
  3. 서버 터미널에서 에러 로그 확인
  4. 데이터베이스에 회원 데이터가 있는지 확인
